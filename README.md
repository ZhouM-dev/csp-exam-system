# CSP 模拟考试系统

公网入口为 **https://csp.liteoj.cn**，由 Caddy 提供 HTTPS。浏览器访问、登录和交卷均使用 HTTPS；文档中的回环 HTTP 地址仅供服务器内部健康检查和评测通信。

教师创建比赛、配置题目与名单；学生使用考号登录，上传考号文件夹交卷。CSP / OI 取最后一次交卷，IOI 按题保留最高分。三种赛制均在比赛结束且教师公布成绩后向学生提供分数和排行榜。

当前架构是 Python 标准库 HTTP 服务、SQLite 业务数据库、文件题库数据、持久 SQLite 提交队列和 HydroJudge + go-judge 评测服务。题面、元信息、比赛、名单与成绩入库；测试数据和学生源码保留为文件。迁移、备份与 LiteOJ 格式导出见 [数据库与题库迁移](docs/数据库与题库迁移.md)。编译、运行、检查器与测试点评分使用原版 HydroJudge；排行榜与管理端共用数据和公开开关。

教师可在题库列表或题目详情点击「导出 ZIP」，将完整题包直接上传到另一台同版本系统的「新建题目」。题面、英文名、限额、标程、数据文件名和样例分类均保留；使用步骤及版本要求见 [题目导出与迁移](docs/题目导出与迁移.md)。

云服务器的 CPU 与官方评测硬件不同。本机独立 CSP 沙箱已经部署并完成实际编译、判题及文件 I/O 验收。集中接收和队列恢复测试不等于 100 人整套卷同时评测容量保证；当前评测并发为 1。时间倍率默认1.0，尚未完成官方同款主机性能校准。

## 版本控制

使用 Git 保存源码、文档与有效回归测试；运行数据、成绩导出、日志、凭据与备份由 `.gitignore` 排除。审计文档仅保存汇总，逐人成绩与原始资料保留在私有恢复档案。

本仓库只保留 `main` 分支，已整合原 `dev`、`codex/contest-schedule-zip` 的全部提交以及上游合并记录。上游仓库为 [ZhouM-dev/csp-exam-system](https://github.com/ZhouM-dev/csp-exam-system)，后续贡献从本仓库 `main` 向上游 `main` 提交 PR。当前服务器上线记录见部署验收文档。禁止强制覆盖共享分支；推送前检查暂存内容和 `git diff --check`。部署按前述脚本执行，业务数据不进入仓库。
