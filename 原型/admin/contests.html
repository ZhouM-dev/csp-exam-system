级别决定考号格式与默认时长：入门级 GD-J58437、提高级 GD-S10029。 全真模式下学生交完只看到「已提交」，不显示任何判分信息（和真实 CSP 第二轮一致）。

三种赛制的区别：提交方式都一样——学生交考号文件夹（上传文件）， 赛制只决定程序怎么写、能不能实时看分、怎么计分。

  • OI 赛制 OI 赛制：国内 OI/NOIP 风格：程序用标准输入输出（cin/cout，不需要 freopen），赛时不显示分数，成绩按最后一次提交计分，老师在管理端点「发布成绩」后学生才能看到分数。
  • IOI 赛制 IOI 赛制：国际信息学奥赛风格：程序用标准输入输出，提交后立刻看到得分，每题取多次提交的最高分。
  • CSP 赛制 CSP 赛制：CSP-J/S 复赛风格：代码必须用 freopen 读写 <编号>.in / <编号>.out；文件夹名或 freopen 文件名写错，这题就是 0 分。赛时不显示分数，赛后老师公布。

三种赛制的共同点：学生都是上传以考号命名的文件夹，里面按系统自动生成的题目编号建子文件夹（T1/T1.cpp）；没有"在网页上粘贴代码"这条路。

广东考区补充要求：考号格式为 GD-J / GD-S + 5 位随机数； 考生还要交一个以自己名字命名的个人信息文本文件（姓名/性别/年级/地区/学校/辅导老师/提交的程序）。
