题单导入接口规范 v1

管理端 · 比赛列表 · 题目列表 · 新建题目 · 原型总览

把一个「出题工程」整包导入评测站（Hydro）。题单结构完全参照现有出题工程的规范 （题目库_规范.md 的定义），导入器按该结构自动识别题面、测试数据与标程。

导入时不用管标识和编号，系统自己分配
下面是出题工程的文件规范（题面放哪、数据怎么命名），照着打包就行。 导入后每道题由系统分配身份，老师选题时按标题找即可，不需要记标识。
所以换题单、改题面、调整题目顺序，都不会让学生已经练熟的编号变样。

一、题单结构规范

一个题单是一个 zip 或一个目录，内部按下面两种形态之一组织（都支持）：

形态 A：标准出题工程（推荐，即现有 zip 的形态）

题单.zip
└── 题目库/                        ← 任意层级的容器目录（可为空，也可叫其它名字）
    ├── _索引.md                   ← 【可选】题单索引表，提供难度与考点
    ├── D01-最小值切分贡献/
    │   ├── 题目.md                ← 【必需】题面（Markdown）
    │   ├── 标程.cpp               ← 【必需】标准程序
    │   ├── 暴力.cpp               ← 忽略
    │   ├── 生成器.py              ← 忽略
    │   ├── D01-洛谷上传.zip        ← 忽略
    │   ├── 大样例/                 ← 忽略（大样例.in/.out）
    │   └── data/                  ← 【必需】测试点
    │       ├── 01.in  01.out      ←   两位数字命名、成对出现
    │       ├── 02.in  02.out
    │       ├── …
    │       └── 样例1.in  样例1.out ←   题目样例：按规范不参与评测，自动忽略
    └── G01-加边后最小生成树/
        └── …（同上）

形态 B：扁平题包（没有分类号时也能用）

题单.zip
└── A+B问题/
    ├── 题目.md
    ├── 标程.cpp
    └── data/01.in 01.out …

字段与命名规则

项目规则说明
题目目录<分类号>-<题名>分类号 = 1~3 位大写字母 + 两位数字（G01/DP01/ST04）；题名用中文，不含 / \ : * ? " < > |
题目标识（pid）取分类号站点上题目的唯一标识，如 G01；形态 B 无分类号时用目录名清洗后的字母数字串
标题取分类号后的题名如 加边后最小生成树
题面题目.md（也认 题面.md/statement.md/problem.md/README.md）Markdown，站点按 Markdown 渲染（支持 $…$ 公式）
测试点data/ 下 <数字>.in + 同名 .out按数字升序重排为站点的 1.in/1.out、2.in/2.out…（前导零无关）
标程标程.cpp（也认 std.cpp/solution.cpp/ac.cpp/correct.cpp）导入后站点会自动编译并评测标程，可用于反向验证数据与标程是否一致
难度_索引.md 的「难度」列按洛谷 7 级标签映射为站点难度 1~7，原始标签保留为标签 难度:<原文>
考点_索引.md 的「考点」列按规范用全角竖线 ｜ 分隔（也兼容 \|、、、,、/），每个考点作为一个标签
时限/内存接口参数（默认 1000ms / 256MB）也可用 --time / --memory 覆盖

自动忽略的文件

*.exe、*-洛谷上传.zip、大样例/、data/样例*、__pycache__/、跑数据.py、暴力.cpp、生成器.py —— 这些是出题过程的附属物，不参与导入（与你现有的洛谷打包规范一致）。

_索引.md 的格式（可选但推荐）

| 编号 | 分类号 | 题名 | 难度 | 考点 | 测试点 | 大样例 | 状态 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 001 | G01 | 加边后最小生成树 | 提高+/省选− | 最小生成树｜树上路径最大边｜增量维护 | 20 + 样例2 | 1 组 | ✅ 已通过 |

导入器只读取 分类号 / 题名 / 难度 / 考点 四列。

二、导入结果

每道题在站点上生成一个题目：

站点字段来源
pid分类号（冲突时：默认跳过，--overwrite 则先删除旧题再导入）
标题题名
题面题目.md
标签参数 --tag 指定的标签 + 考点 + 难度:<原文>
难度难度标签映射值（1~7）
时限/内存接口参数
测试点data/<数字>.in|.out 顺序重排后的全部数据（样例不参与评测）
标准程序标程.cpp（导入后自动评测，可在题目页「提交记录」里看到结果）

三、命令行接口

python3 import_problemset.py <zip 或 目录> [选项]
选项说明
--tag 名称额外打上的标签，可重复；例如 --tag 寒假作业 --tag CSP-J
--time 毫秒时限，默认 1000
--memory MB内存，默认 256
--only G01,D01只导入指定题目标识（逗号分隔）
--overwrite站点已存在同标识题目时先删除再导入（默认跳过）
--dry-run只解析并生成题目包、打印报告，不导入站点（用于先检查结构）
--workdir 目录题目包输出目录（默认临时目录，导入后自动清理）
--json 报告.json把结构化报告写到文件

退出码：全部成功 0；有题目校验失败 1。

示例：

# 先干跑，确认识别结果对不对
python3 import_problemset.py 题单.zip --dry-run

# 正式导入，并打上"寒假作业"标签
python3 import_problemset.py 题单.zip --tag 寒假作业 --time 2000 --memory 512

# 只导入两道题，覆盖同名题目，并留档报告
python3 import_problemset.py 题单.zip --only G01,D01 --overwrite --json /root/report.json

四、HTTP 接口（教师端）

服务地址：http://<你的服务器IP>:8080（管理密钥见服务器 /root/csp-exam/data/admin_key.txt）。

1) 提交导入任务

POST /api/problemset/import?key=<管理密钥>
Content-Type: multipart/form-data
表单字段必需说明
file是题单 zip 文件（字段名也接受 zipfile）
tag否额外标签，可重复
time否时限（毫秒）
memory否内存（MB）
only否只导入指定标识，逗号分隔
overwrite否1 表示覆盖同名题目
dry_run否1 表示只解析不导入

响应（立即返回，导入在后台进行）：

{
  "ok": true,
  "job": "ps-1727262000-ab12cd",
  "message": "已接收题单（114.9 MB），正在后台导入",
  "report_url": "/api/problemset/report?key=...&job=ps-1727262000-ab12cd"
}

2) 查询导入进度与报告

GET /api/problemset/report?key=<管理密钥>&job=<任务号>

导入中：

{ "ok": true, "state": "running", "progress": "已导入 5/17：G01 加边后最小生成树" }

完成后（state 为 done / failed）：

{
  "ok": true,
  "state": "done",
  "report": {
    "total": 17,
    "imported": ["G01", "G02", "..."],
    "skipped": [],
    "failed": [],

    "problems": [

}

3) 错误码

HTTP场景
400没有上传文件 / 不是 zip / 表单不合法
403管理密钥不正确
404任务号不存在
413上传文件过大（上限 512MB）

教师端页面已内置同一接口的上传表单：/admin?key=… → 「导入题单」。

五、注意事项

  1. 样例不参与评测：data/样例*.in/out 与 大样例/ 一律忽略（与你现有洛谷打包规范一致）；导入的测试点只有 data/<数字>.in|.out。
  2. 幂等：同一份题单重复导入，站点已有的题目会被跳过并在报告里列出；确需覆盖用 --overwrite（会删除旧题目及其提交记录，慎用）。
  3. 标程即质检：导入后站点会自动编译并评测标程。若标程不是 AC，说明该题的数据或标程有问题，可在题目页「提交记录」里看到具体判定（这是导入环节自带的免费质检）。
  4. 题目包落盘位置：宿主机 /root/hydro/data/backend/import/<pid>/（容器内 /root/.hydro/import/<pid>/）。注意这两个路径的对应关系，命令行里要用容器内路径。
  5. 大文件：数据文件按流式复制，不会整包读进内存；单次上传上限 512MB。
  6. 编码：题面与标程按 UTF-8 读取，遇到 GBK 会自动回退（Windows 下生成的文件常见）。
