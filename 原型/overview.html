CSP 训练站 · 原型页面总览

这是本地静态原型：数据全部写死，只用来确认界面与流程，还没有接后端。 样式与文案从线上系统原样提取，并已按广东考区真实规则对齐（考号格式、个人信息文件、交卷检查、全真模式）。
要动手改线上系统时：先看 《整改清单》（改动全貌与「改哪里」），再看 《任务清单》（拆成 12 个可并行的任务，每个任务占哪些文件、怎么验收都写好了）。

一、先看这两处：本轮的改动

二、题目编号：为什么改成系统自动生成

现在老师不用再填「题目英文名」，学生也不用去题面里找。规则很简单：

第几题题目编号文件夹源文件freopen 的文件
第 1 题T1T1/T1.cppT1.in / T1.out
第 2 题T2T2/T2.cppT2.in / T2.out
第 3 题T3T3/T3.cppT3.in / T3.out

好处：老师配题时只要按顺序把题加进来就行，不会因为英文字母写错、 换个题单、或出题工程里分类号不统一，让学生整场都交到错的地方。

老师界面上不再出现任何题目标识：新建题目时系统分配、选题时按标题找， 都不用填、不用记。想换编号格式（比如小写 t1、或带场次前缀）只改一处生成规则即可。

二、这是给谁用的、怎么走一遍

两个人用：学生只做三件事（进考场 → 看题写代码 → 交上去），老师做四件事（建比赛 → 发考号 → 建题目 → 出成绩）。

学生：打开本场链接 → 输考号 → 看考生须知 → 看题面 → 交文件夹 → 核对检查清单 老师：建分组 → 建比赛（选级别/时长/模式）→ 建题目 → 导入名单发考号 → 打印考号表 → 看成绩总表 → 点进详情讲评 → 公布成绩

推荐按这个顺序点一遍：考生须知 → 考场入口 → 比赛页 → 题面 → 交卷回执，然后从 管理端比赛列表 走到 本场管理 → 成绩总表 → 提交详情。

五、两级 × 三赛制

级别决定考号格式和考试时长：

级别考号示例时长
入门级 JGD-J584373.5 小时
提高级 SGD-S100294 小时

考号的 5 位数字是纯随机数，不是从 1 顺着排的——和学生姓名、名单顺序、机位都无关，同一场不重号，不同场次各发各的。

赛制只影响三件事：怎么判分、是否实时看分、怎么计分。 提交方式三种赛制都用「上传文件」——学生一律交考号文件夹，没有"在网页上粘贴代码"这条路。

赛制程序怎么写学生看分计分看哪页
OI 赛制标准输入输出
不用 freopen		赛中不看，赛后公布每题最后一次提交比赛页 · OI
IOI 赛制标准输入输出
不用 freopen		提交后立刻看分每题最高分比赛页 · OI
CSP 赛制freopen 读写 <编号>.in/.out赛中不看，赛后公布每题最后一次提交比赛页 · CSP

反馈模式是本轮新增的开关：

模式赛中反馈适合
全真模式零反馈，只有「已提交 / 未提交」考前全真模拟（对齐真实 CSP 第二轮）
训练模式交完即判分，逐题给状态平时练习、边练边讲

六、原型里可以点的交互（都只是前端假动作）

  • 考试入口、考场入口：输入任意考号 → 进入比赛页
  • 比赛页：倒计时是真的在走（提高级 4 小时起算，刷新页面不重置；最后 30 分钟变红）
  • 比赛页：选文件夹 →「提交我的代码」→ 交卷回执页
  • 题面：公式是真的 KaTeX 渲染（不是图片）
  • 新建题目：点「预览」开悬浮窗看学生视角（改题面实时更新，Esc 或点空白处关闭）；标程可在代码框里直接改
  • 管理端的表单是静态的，按钮不提交（避免误导）
  • 想重置倒计时：浏览器控制台执行 resetCountdown() 后刷新
