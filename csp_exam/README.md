# 使用说明

教师从 `/admin` 登录，管理密钥保存在服务器 `data/admin_key.txt`。进入站内后使用管理会话，无需反复输入密钥。

比赛列表可以新建和删除比赛。创建时选择赛制、级别与时长，再在本场管理中设置题目、名单和考号前缀，点击保存。分组保存常用学生名单，本场名单独立生成随机考号；已有提交后禁止重排考号。删除比赛会删除本场名单、成绩和交卷文件，题库保留。

题库提供新建、查看/编辑题面、修改题目名称和限额、自己测试、重传、删除及恢复。题目编号由系统分配，英文名用于学生文件夹、源码和输入输出文件命名。新建可选整个出题文件夹、zip 或成对数据；每道题必须有标准答案。多个题目按各自目录独立导入。批量 API 与网页建题使用同一套本地题库流程。软删除保留资料；彻底删除会拒绝仍在比赛中使用的题目。

学生使用本场考号登录。CSP 按 `<考号>/<英文名>/<英文名>.cpp` 提交，并按题目要求使用文件输入输出。系统直接编译原始源码，区分大小写，不注入包装代码。个人信息文本用于提醒。上传回执表示交卷已收到，分数和运行结果由教师公布后可见。OI / IOI 使用相同交卷入口，其输入输出规则与计分方式由赛制决定。

管理端排行榜、成绩总表、学生成绩页使用同一排名和总分投影，只计算本场题目和名单。同分并列，未完成或需处理的记录不参与排名。教师点击姓名或分数可查看提交详情，分数定位到对应题目并展开源码；详情提供逐点输入、输出、标准答案、时间、内存和代码下载。排行榜支持搜索、比赛切换与刷新；公开榜跟随本场“公布/收回成绩”开关。

管理端提交详情可以重测。重测冻结本次使用的题目、赛制、限额和倍率，保留旧成绩与源码快照。修改比赛题目后撤回公开成绩；更换题目数据或修改评测限额后，相关旧成绩撤回并标记需重测。队列未完成、资料不足或成绩与当前题目不一致时拒绝公布。缺失的历史资料不能作为零分或成功评测处理。

评测设置显示实际编译环境、CPU 与倍率。倍率可按实测基准配置，报告同时保留官方时限和生效时限；当前默认 1.0，未完成官方同款主机校准。环境依据、与官方硬件的差异见 [环境审计](../docs/CSP评测审计-2026-10-06.md)。
