# 题单导入接口

题单为 zip 或目录，每题放在独立目录中，例如 `题目库/G01-加法/`；目录内有 `题目.md`、`标程.cpp` 和 `data/01.in`、`data/01.out` 等成对数据。支持 `题面.md` / `statement.md`、`std.cpp` / `solution.cpp` 等候选名。分类号是内部题目标识，题目编号由系统分配；默认英文名可在导入或本场配置时设置。

数字命名的输入和同名输出是评测数据。题目样例、大样例等附件可由出题文件夹上传识别，不计入测试点。每题需题面、标程及至少一对数据；缺项返回失败报告。同标识默认跳过，显式 overwrite 时覆盖；在途评测拒绝换数据，已有成绩撤回并要求重测。

```bash
python3 -m csp_exam.core.importer 题单.zip --dry-run
python3 -m csp_exam.core.importer 题单.zip --code G01=sum --time 1000 --memory 256
```

`dry-run` 仅校验，不分配编号、不写题库。导入与网页建题使用同一流程，保存题面、数据、标程和评测限额。上传上限为 512MB，zip 解压后的总量亦不得超过 512MB 或 20000 个文件；越界及重复路径拒绝。

教师登录后向 `POST /api/problemset/import` 发送 multipart 表单，文件字段 `file`；可选字段 `code`（如 G01=sum）、`time`（毫秒）、`memory`（MB）、`only`（逗号分隔标识）、`tag`、`overwrite` 和 `dry_run`。也支持管理密钥参数，但建议使用站内管理会话。

成功接收返回 `{ok:true, job:任务ID, report_url:查询地址}`。轮询 `GET /api/problemset/report?job=任务ID` 获取 `running`、`done` 或 `failed` 及报告；报告包含成功/跳过/失败题目、编号、英文名与失败原因。原上传文件在任务结束后删除；状态只保留最近的已完成任务，服务重启后不保留查询状态，已导入的题目永久保存。

403 表示管理鉴权失败，400 表示上传格式或内容无效，429 表示同时导入数量已满。没有识别到题目时返回失败，不能把空题单当成功。
