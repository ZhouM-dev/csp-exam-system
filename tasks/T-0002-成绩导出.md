## 要做什么

老师在「成绩总表」页（`/admin/scores?c=<比赛>`）只能看，不能存。
每场考完都要把成绩交给学校/教研组，现在只能靠截图。要加一个**导出**按钮：

- 成绩总表页右上角一个「导出 CSV」按钮 → 下载 `<比赛id>-成绩-<日期>.csv`
- 内容与页面上的表格一致：`考号, 姓名, 第1题, 第2题, …, 总分, 提交时间`；
  未交的题写 `-`（和页面上的显示口径一致，用 `grading.graded_cell` / `store.entry_total`）
- **编码**：`utf-8-sig`（带 BOM），否则 Excel 双击打开中文全是乱码
- **权限**：必须带 `key=<管理员key>` 才给下载（和其它 `/admin/*` 页一个口径，用 `self._check_admin()`）
- 文件名用 URL 编码（中文文件名在部分浏览器上会出问题，用 `urllib.parse.quote`）
- 表头行冻结那一类花活不做，纯 CSV 就行

实现要点：`/admin/export?key=…&c=…` 走已有 `_send`/响应方式返回
`Content-Type: text/csv; charset=utf-8` + `Content-Disposition: attachment; filename*=UTF-8''…`。
不要新建一套表格渲染——直接复用 `store.ranking(cid)` 和 `store.entry_total()`，
保证导出结果和页面**永远一致**（这是这个任务唯一容易出错的地方）。

- 不要动数据文件（`data/**`）

- 不要 git 提交（本项目不依赖 git）
