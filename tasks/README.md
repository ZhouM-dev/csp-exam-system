# 任务板

所有待办/进行中的改动都写成 `tasks/T-00NN-短名.md`，一个任务一个文件。
**并行协作的规则**见《[协作规范](../docs/协作规范.md)》。

## 怎么用（30 秒）

```text
1. 复制 tasks/_模板.md → tasks/T-00NN-短名.md        （建任务：定车道 + 文件白名单）
2. 在 tasks/lanes.md 的"当前占用"里登记一条            （声明你不和谁撞车）
3. 新开一个对话，把下面这段发给它：
      执行 tasks/T-00NN-短名.md。只改白名单里的文件；
      改完跑 runtime\python\python.exe build\_check_all.py，
      再用 build\_ship.cmd 部署并跑冒烟；按"产出"逐项打勾，状态改"待验收"。
4. 完成后：把任务文件的状态改成 待验收/已完成，并在末尾写一段改动摘要。
```

## 任务一览

| 编号 | 标题 | 车道 | 状态 |
|---|---|---|---|
| [T-0001](T-0001-G01数据重做.md) | G01 数据/标程重做（标程超 5s） | C 业务核心 | 待认领 |
| [T-0002](T-0002-成绩导出.md) | 管理端导出成绩表（CSV） | B 管理端 | 待认领 |
| [T-0003](T-0003-学生端帮助页.md) | 学生端「怎么交」帮助页 | A 学生端 | 待认领 |

> 状态只有五种：`待认领` / `进行中` / `待验收` / `已完成` / `已阻塞`。
> 一个任务同时只能被一个对话认领；想并行就在 `lanes.md` 里选不同车道。
