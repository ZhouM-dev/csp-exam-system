# 任务板

所有待办/进行中的改动都写成 `tasks/T-00NN-短名.md`，一个任务一个文件。
执行规则见 [开发与验收规范](../docs/协作规范.md)。当前串行执行，用户要求并行时才分配不同执行者。

## 执行流程

1. 从 `tasks/_模板.md` 建立任务，记录目标、文件范围与数据保护约束。
2. 在 `tasks/lanes.md` 登记负责范围。
3. 修改后运行 `bash tests/_regress_all.sh --quick`；涉及评测/提交/管理动作时在沙箱服务器运行 `--live`。
4. 使用 `bash csp_exam/tools/deploy.sh admin@服务器` 部署，检查只读冒烟与数据保护清单。
5. 更新文档和任务状态，记录真实验证结果，释放占用。

历史待办需要按当前实现重新核对，不能直接执行当时的数据修复脚本。
