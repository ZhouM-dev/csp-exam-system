# T-0010：Git 版本控制与远端推送

- 用户授权：使用 Git 进行版本控制并推送远端，覆盖早期任务中“未经要求不提交”的限制。
- 范围：本轮已验证的源码、测试、清理与文档变更；`.gitignore`、根 README 和当前任务。
- 远端：`git@github.com:HydraBor/csp-exam-system.git`。
- 分支：沿用当前 `dev`，设置 `origin/dev` 为上游；正常推送，不强制改写历史。
- 数据约束：运行数据、密钥、原始交卷、逐人成绩与私有审计原件均不纳入 Git。敏感审计文档先留私有原件，再保存仓库汇总版。
- 验证：已有本机与服务器回归通过；推送前核对暂存文件、凭据特征与空白错误，推送后核对远端分支 SHA 和工作区状态。
