## 要做什么

现在的实际情况：考试当天学生会问"文件夹怎么传""代码里要不要写 freopen""传错了怎么办"，
老师要在群里重复回答。要在学生端加一个**一页讲完**的静态帮助页 `/help`：

1. **三种赛制怎么交**（按当前比赛自动高亮，没有比赛就三个都列出）
   - OI：网页里粘代码，最后一次提交算分，考完才出分
   - IOI：网页里粘代码，随时看到分数，每题取最高分
   - CSP：交「考号/题目英文名/代码」这个文件夹，看不到分数
2. **CSP 文件夹长什么样**：一个示例目录树（**用 `ui.folder_tree()` 或纯文本示例**，
   不要写成某个真实比赛的题号，用 `candy / apple 这类示例名`）
3. **三条最容易踩的坑**（各一句话，不要长篇）
   - 文件夹名和题目英文名要**完全一致**（大小写、连字符）
   - 代码里按题目要求写 `freopen`，文件名写错这题就是 0 分
   - 只传源码，别把 `.exe`、`.o`、`__pycache__`、压缩包里的临时文件也传上来
4. **页面导航**：学生端每页顶部导航加一个「怎么交」入口（`ui.py` 里的学生导航）
5. 页面底部一句："还是不清楚就直接举手问老师"

写页面时用现成的 `ui.page()` 外壳和 `.card` / `.tree` 样式，**不要新增 CSS 类**；
文案要短，全页读完不超过 1 屏半。**不要**在页面上放管理端链接、不要放评测站链接。

## 不要做什么（边界）

- 不要改判分、成绩、数据（C 车道的事）
- 不要在帮助页里写死某一场比赛的题目英文名（会过时）
- 不要为了这个页面动 `web/static/**`
- 不要 git 提交（本项目不依赖 git）
