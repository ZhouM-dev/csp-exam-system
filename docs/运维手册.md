# 运维手册

当前站点为 https://csp.liteoj.cn。使用现有服务器，与 LiteOJ 分开部署。公网 HTTPS 由 Caddy 自动签发和续期证书；回环后端不直接开放公网。当前代码、环境和验收见 [服务器上线记录](服务器上线-2026-10-11.md) 和 [成熟评测服务](成熟评测服务.md)。历史审计中的服务器、目录及旧判题实现不适用于本部署。

| 项目 | 当前值 |
|---|---|
| 网站 | `csp-exam.service`，127.0.0.1:8081，账号 `csp-exam` |
| Hydro | Docker `csp-hydro-bridge`，127.0.0.1:8082，私密 Bearer token |
| 沙箱 | Docker `csp-go-judge`，127.0.0.1:5060，独立 G++ 9.3.0 |
| 代码 | `/opt/csp-exam/current`，指向带日期的只读发布目录 |
| 业务正本 | `/var/lib/csp-exam` |
| 日志 | `/var/log/csp-exam`；容器日志限制 10 MiB × 3 |
| 配置 | `/etc/csp-exam.env`、`/etc/csp-hydro.env`，root 0600 |
| Caddy | `/etc/caddy/Caddyfile`，只增加 CSP 站点块 |
| 初次备份 | `/var/backups/csp-exam`，root 私有 |

不要操作 `liteoj-app`、`liteoj-go-judge`，不要批量重启 Docker、删除容器或覆盖 LiteOJ 的 Caddy 配置。

下面的 `http://127.0.0.1` 仅在服务器本机使用。公网统一使用 `https://csp.liteoj.cn`，这些后端端口不开放公网。

```bash
ssh liteoj@liteoj.cn
sudo systemctl status csp-exam --no-pager
sudo journalctl -u csp-exam -n 80 --no-pager
sudo docker logs --tail 80 csp-hydro-bridge
sudo docker logs --tail 80 csp-go-judge
curl -fsS http://127.0.0.1:8081/health
curl -fsS http://127.0.0.1:8082/health
```

服务开机自动启动。网站保持单进程，业务和题面正本位于 `csp-exam.sqlite3`，提交队列位于 `judge-queue.sqlite3`。交卷先归档，再放进持久队列；重启恢复未完成任务。并发固定为 1，可用内存低于 1536 MiB 时暂停开始新任务，学生仍能交卷。沙箱故障退避重试，不用系统错误覆盖已经确认的成绩。迁移和兼容导出见 [数据库与题库迁移](数据库与题库迁移.md)。

上线后通过 `/admin/login` 使用管理密钥登录。密钥在业务正本 `admin_key.txt`，不要放在 URL、代码仓库、截图或公开源码包中。管理端设置比赛开考和结束时间、四题及名单。开考前隐藏题面，截止后后端拒绝交卷；服务端时间是最终依据。时间和名单以管理端当前配置为准；初次导入时的草稿状态不是当前状态。候考页显示比赛信息及倒计时，到时自动进入考试页。

比赛文件资料位于 `contests/<id>/`；源码快照、TXT、原始交卷、重测记录及数据库内成绩都是业务资料，不能作为缓存清理。`problems/`、`samples/` 和数据库内的题面及题目记录属于题库。只有 `hydro-work` 与沙箱缓存是受控临时评测材料，正式比赛和在途任务期间也不要手动删除。

代码升级先在本地构建源码包并运行自测，上传到新的 `/opt/csp-exam/releases/<版本>`，核验 `RELEASE-MANIFEST.json`。业务数据始终留在 `/var/lib/csp-exam`；不要覆盖。空闲期切换 `current` 并只重启 `csp-exam.service`。容器升级须使用当前锁文件和构建文件，避免临时采用未验证版本。源码回滚不等于成绩或题库回滚；恢复数据前保全最新交卷。

一致性备份工具要求网站停止写入，不要在考试中运行。选择空闲期，只停止 CSP 网站，备份结束后恢复：

```bash
sudo systemctl stop csp-exam
sudo python3 /opt/csp-exam/current/csp_exam/tools/backup_data.py \
  /var/lib/csp-exam /var/backups/csp-exam/自选不重复文件名.tgz
sudo systemctl start csp-exam
```

备份文件 0600，仅管理员可读。另保留私有环境配置、Caddy 配置和对应源码发布包。不要仅备份 Git 仓库后认为学生资料已备份。

完整实机回归需要 root 启动可删除的临时 Hydro 容器，临时应用随后降权为 `csp-exam`。夹具只写独立临时目录，不修改生产成绩；共享沙箱会消耗资源，请在空闲期执行：

```bash
sudo bash -c 'set -a; . /etc/csp-exam.env; set +a; cd /opt/csp-exam/current; bash tests/_regress_all.sh --live'
```

`/source/` 提供适配源码、锁文件、构建文件和原版 Hydro 对应源码，履行开源许可。公开目录不放题库、答案、学生资料和密钥。
