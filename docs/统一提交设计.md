# 统一提交入口 · 2026-10-11

文件夹与ZIP共享一个提交卡片、一个选择按钮、一个待提交清单和一个提交按钮。选择按钮使用Tabler现成Dropdown；上传区域使用官方Empty state、卡片与按钮类，没有新增通用主题。

## 设计依据与落地

|公开依据|在本项目的应用|
|---|---|
|[Tabler官方Dropdown](https://docs.tabler.io/ui/components/dropdown)|把文件夹/ZIP选项放入同一个选择菜单，页面保持单一入口。|
|[Tabler官方Empty state](https://docs.tabler.io/ui/components/empty)|使用现成图标、标题、说明和操作按钮布局；供应商CSS/JS保持原始字节。|
|[GOV.UK File upload](https://design-system.service.gov.uk/components/file-upload/)|同时提供选择按钮与可见拖放区域，显示选中状态，交互文案保持简短。引用其交互原则，没有替换为GOV.UK皮肤。|
|[W3C WAI表单说明](https://www.w3.org/WAI/tutorials/forms/instructions/)|明确允许的格式、考号外层和大小上限；选择按钮关联说明；状态使用aria-live，错误通过文字提示。|

这些是组件和可用性参考，不宣称界面美观存在唯一量化标准，也未声称已完成所有WCAG符合性认证。

## 提交行为

- 原生文件选择器不能用同一个input同时选择目录和ZIP。内部保留两个隐藏input，用户在同一菜单选择类型；页面只有一份提交表单。
- 支持拖入一个考号文件夹或一个ZIP；不支持把散落的代码文件当作完整目录提交。选择新内容会替换旧选择，移除后提交按钮禁用。
- 选择文件夹时保留webkitRelativePath；拖放目录递归读取全部批次，避免浏览器每批最多100项造成漏文件。使用原生表单导航，FormData按原始相对路径发送，不把目录压平。
- 待提交清单最多展示100项，其余明确显示剩余数量，所有文件仍提交。读取上限1024个文件、32层目录、配置的上传字节上限（默认32MiB）；阻止重复路径、空目录、超限和读取中的提交。
- 考号外层、同名子目录与.cpp、大小写、中文姓名.txt/.TXT的服务器校验保持。个人信息文件属于已核验广东考区细则，不能自动外推为全国统一要求。
- 服务器仍按赛程接收，并在上传读取后重新检查截止。赛中回执只核对文件结构，不显示编译、测试点或分数。

## 已执行的验收

`node csp_exam/tests/selftest_submission.js`通过：文件夹路径与TXT、ZIP替换、multipart原始文件名、重复/非法路径/大小/数量/空目录拒绝，以及101个文件的多批次读取。

浏览器实际通过文件夹选择与ZIP选择分别提交修订版四份代码，回执完整识别5个文件及字面freopen；没有连接评测沙箱。390像素窄屏不撑破页面，选择菜单可通过Enter打开，选中后移除恢复禁用状态。实际目录拖放未由UI工具自动化驱动，其遍历与路径保留由上述专项覆盖。

当前只在内置Chromium验收。旧浏览器和不支持目录API的浏览器需使用ZIP；页面明确提示需要启用JavaScript。实际截图在项目外《平台/界面验收》，运行数据与测试工具不进入源码发布包。
