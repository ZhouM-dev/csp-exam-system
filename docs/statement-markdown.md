# 题面 Markdown 与数学公式

学生题面和管理端预览使用同一份 Markdown 转换逻辑，再由本地 KaTeX 渲染公式。

数学变量、下标、指数、约束必须写在公式定界符内。普通文字 `a_i`、`10^5` 不会自动变成公式；自动猜测也可能误改文件名和代码。

```markdown
第 $i$ 批有 $a_i$ 名学生。

对于所有数据：$1 \le n \le 10^5$，$0 \le a_i \le 10^9$。

$$
N = \sum_{i=1}^{m} a_i
$$
```

统一使用 `$...$` 行内公式和 `$$...$$` 显示公式，包括多行显示公式。公式中的乘号等字符不会被 Markdown 的粗体、斜体规则改写。

输入输出文件名、样例及源代码使用行内代码或围栏代码块。代码块里的 `$`、`$$` 与反斜杠保持原样，不执行公式渲染。HTML 内容会转义，题面不能插入脚本。

发布前应在管理端右侧预览检查下标、指数、约束表和样例；修改题面后，学生重新打开题面即可读取最新内容。
