# 学生候考、退出与排行榜权限修复

学生比赛页与交卷回执赛中隐藏查成绩和排行榜入口；结束且教师公布成绩之后才显示。公开排行榜 HTML 与 JSON 接口同样检查时间窗口和公布状态，拒绝时返回 403，不包含考生、题目或成绩数据。已经公布过的响应缓存、提前置为已公布的异常数据、结束时间重排都不能绕过限制。

普通 `/scoreboard` 始终展示公开视图，不再因为同一浏览器曾登录管理端就自动升级为教师视图。教师通过 `/admin/scoreboard` 或鉴权通过的 `/api/scoreboard?private=1` 查看成绩；学生无管理员凭据不能使用这些入口。公开页不保留管理密钥。已打开的排行榜遇到撤回或拒绝时清空表格。

学生未设时间、候考、考试进行中、结束后的页面均提供小尺寸「退出登录」按钮。退出删除学生 cookie 并返回本场 `/enter?c=...` 考号登录页，随后访问考试页须重新登录；管理登录不因学生退出而变更。

候考界面采用现有 Tabler 1.6.1 的卡片、徽章、Data grid 和按钮，展示本人姓名／考号、组别、赛制、北京时间的起止时间、时长以及倒计时；开考前不提供题名、英文名、题目编号、试题或提交入口。布局依据 [Tabler Card](https://docs.tabler.io/ui/components/card)、[Data grid](https://docs.tabler.io/ui/components/datagrid) 和现有官方页面模板，继续使用项目已收录的原版组件资源。

倒计时按服务器时间与浏览器单调时钟推进，每两秒校验考试状态；到零立即尝试确认，只有服务器返回 running 才自动进入本场 `/hall`。客户端修改系统时间不提前解锁，断网自动重试，重新安排时间更新候考页。服务器已确认 NTP 同步。用户提到的 [time.is 时钟组件](https://time.is/widgets)明确要求页面不得自动刷新，故本次采用服务器时间接口以满足开考自动进入要求，没有引入第三方时钟依赖。

验收日志与上线版本见交付目录的 r6 记录。本次不修改学生目录规范、题目数据、计分方式或 LiteOJ 服务。
