## 实际部署

服务器为 Ubuntu 24.04.4 / cgroup v2，2 CPU、约 3.4 GiB 内存、无 swap。遵照用户要求只使用当前服务器。

| 服务 | 地址与限额 |
|---|---|
| CSP 网站 `csp-exam.service` | 127.0.0.1:8081；独立账号；0.5 CPU、512 MiB 上限 |
| 原版 HydroJudge 4.0.6 `csp-hydro-bridge` | 127.0.0.1:8082；0.5 CPU、256 MiB；私密鉴权、非 root、只读容器 |
| 原版 go-judge v1.12.0 `csp-go-judge` | 127.0.0.1:5060；1 CPU、1536 MiB；独立沙箱、缓存及 UID/GID 段 |
| LiteOJ 网站及沙箱 | 保留既有 3000 / 5050 端口、数据卷与容器 |

CSP 代码为 `/opt/csp-exam/releases/20261011-r5`，`/opt/csp-exam/current` 指向该版本；业务正本 `/var/lib/csp-exam`，日志 `/var/log/csp-exam`。配置私有，网站和两个评测容器开机启动。网站只允许一个进程写业务数据。

原版 HydroJudge 负责所有判题流程，没有旧 Python 检查器或自动降级。适配层负责题库与结果映射。G++ 9.3.0 / C++14 / O2 / static；上游 strict_memory 配置使栈跟随题目内存。云主机性能未与官方硬件标定，时间倍率 1.0。

go-judge 二进制从现有沙箱只读提取，版本 v1.12.0，记录 SHA256 `2ecef4151b13da0fe38d919a75c4fe2621d94e69802325f52558985d6829b232`；未独立完成官方校验和表比对。学生程序沙箱 UID/GID 为 1536，宿主映射到独立 20001 及以上身份，NoNewPrivs、cgroup v2 已验证。本二进制默认未启用可选 seccomp，不宣称已启用。

Caddy 先保存原配置，再只添加 CSP 站点与 `/source/` 静态源码入口，验证通过后 reload。LiteOJ 容器 ID 和启动时间前后相同，未重启、重建或调整资源限额；部署与验收期间 LiteOJ HTTPS 首页均返回 200。

## 卷面与界面

已导入普通版四题 `J001R2T1` 至 `J001R2T4`，配置比赛 c1「CSP-J 模拟赛 001（常规仿真）」：210 分钟、四题各 100 分。这是首次上线时的草稿配置；后续时间和真实名单已经由管理员调整，以管理端当前状态为准。原强化第三、四题 `J001XT3/4` 单独保留在题库。常规第三、四题改为“彩灯布置”“巡检路线”，它们分别去掉逐类连续上限、最短路线方案数，属于模型简化；提交英文名仍为 `label`、`transit`。

学生和教师均采用既有 Tabler 模板。管理端按钮、间距、导航、表单与窄屏表格统一；新建和更新题目材料共用一个文件夹/ZIP 菜单。替换上传内容时自动识别字段不会残留上一份题包的题面或标程。设计依据及具体范围见 [管理端界面调整](管理端界面调整.md)。

考生目录仍为 `考号/英文名/英文名.cpp`，并按题面进行文件输入输出；TXT 附属资料按原始字节保留。个人信息 TXT 的要求依据广东考区资料，不描述为全国统一要求。

## 实际验收与边界

- 本地与服务器 15 套逻辑自测通过；前端提交与倒计时脚本测试通过。
- 服务器完整实机回归：管理 HTTP 198 项、实际交卷/重测 HTTP 29 项、环境与沙箱 16 项全部通过。管理回归含原版 Hydro 的真实标程自测。Linux 未安装宿主 Node，内联 JS 语法检查已在本地完成。
- 原版引擎 AC、WA、CE、RE、TLE、MLE、标准输入输出、文件输入输出、空白差异、非 UTF-8 字节、沙箱无法连接宿主 LiteOJ 回环服务经过实际执行。严格内存模式下，分配失败可以呈现 RE；缺失 `.out` 的 RE 可覆盖资源状态，详见成熟评测服务文档。
- 最新配置上六道题均 100 分，每题 20 点；普通卷 80 点全部通过，总分 400；强化两题 40 点全部通过。
- 在独立非公网验收服务，以 20 客户端线程发送 100 份单点题交卷：50 份目录、50 份 ZIP，100 份 HTTP 200，约 3.062 秒完成接收，源码与 GBK TXT 的字节均一致。
- 暂停评测积累 100 个持久任务，重启验收网站后恢复，100 份全部由 Hydro 完成评测、满分，队列清零。
- 公网教师登录、比赛列表、统一上传菜单已由浏览器确认，并保存线上截图；本地原生文件选择器完成目录导入及替换为不同 ZIP 的导入，落盘题面、标程和数据核对一致。

100 份测试验证的是集中接收、字节归档与重启恢复；每份使用一道单点题，**不能据此宣称 100 人整套卷同时评测的性能已验证**。当前评测并发 1，内存不足 1536 MiB 时延后启动任务，集中交卷会排队。正式考试前应以计划使用的题包和提交量预留评测时间。

汇总证据位于服务器 `/var/log/csp-exam`：`live-regression-summary.json`、`live-regression.log`、`exam-acceptance.json`、`engine-acceptance.json`、`burst-acceptance.json`、`restart-acceptance.json`。验收假名单和临时题库与生产分开，归档后清理。
