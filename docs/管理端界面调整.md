# 管理端界面调整依据

直接采用既有 Tabler Core 1.6.1 模板和组件，保留 vendor 原始文件；业务适配层只处理页面布局与交互，不另造一套前端设计系统。

依据 [Tabler 按钮组件](https://docs.tabler.io/ui/components/button)：主要操作使用 primary，次要操作使用 outline-secondary，列表内操作使用小号按钮；移除旧的超大内联按钮样式，表单按钮保持内容宽度，列表按钮可换行。

依据 [WCAG 2.2 目标尺寸说明](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html)：该准则的通常最低目标尺寸为 24×24 CSS 像素，包含例外。本次管理端小按钮至少 32 像素高，普通按钮至少 36 像素高；这是一项尺寸检查，不宣称完整 WCAG 合规。

参考 [GOV.UK 文件上传组件](https://design-system.service.gov.uk/components/file-upload/) 的清晰标签、提示、选择结果和错误反馈。GOV.UK 文档不是文件夹上传规范；平台在一个上传区域中提供原生目录与 ZIP 选择菜单，明确显示已选内容，并支持清空和替换。

修复下拉菜单项与移动端导航开关被错误套用大按钮样式；去掉重复页面标题；侧栏采用浅色并标明当前页面；统一题目材料区域，长格式说明折叠；窄屏表格在自身容器内横向滚动。样式及脚本附带版本或重新验证缓存，避免旧页面资产掩盖改动。
