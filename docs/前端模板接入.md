# Tabler 前端模板接入

本次采用 **Tabler Core 1.6.1 免费版**。选型时比较了 Tabler、AdminLTE 和 CoreUI 的官方资料；当前平台输出服务端 HTML，Tabler 可直接接入，不需要另建 React/Vue 前端或引入 Node 构建服务。

## 来源与许可

- [Tabler 官方介绍](https://tabler.io/admin-template)。
- [官方布局与侧栏示例](https://docs.tabler.io/ui/layout/page-layouts)。页面外壳采用这些布局，登录页采用官方 `page-center` / `container-tight` / `card` 组件。
- [官方源码与 MIT 许可证](https://github.com/tabler/tabler)。本次没有使用收费 Pro 模板或额外付费组件。
- 编译后的 CSS、JS 来自 [官方 npm 包 @tabler/core 1.6.1](https://www.npmjs.com/package/@tabler/core/v/1.6.1)，下载时核对 npm SHA-512 integrity；落盘文件保持原始字节。
- 保存 Tabler、Bootstrap、Popper 的许可证，并通过 `vendor-manifest.json` 记录 SHA-256 与原始来源。

## 接入范围

| 页面 | 使用的现成组件 |
|---|---|
| 教师登录、学生入口 | 官方居中登录布局、卡片、输入框、按钮、提示信息 |
| 管理端各页 | 官方纵向侧栏、页面标题、表单、徽章、表格、按钮 |
| 学生考场、题面、须知、回执、成绩 | 官方普通页面布局、卡片、响应式表格、提示信息 |
| 排行榜 | 同一页面外壳和卡片组件；保留原有搜索、刷新、排名与分数状态 |

没有重新设计一套通用主题。新增代码是模板占位与原有页面的适配层：给服务端 HTML 和动态生成的表单加 Tabler 类名，保留路由、表单字段、文件夹选择属性、元素 ID 和原有业务脚本。倒计时、目录树、逐点判定及现有弹窗需要的专用样式从原代码移到 `exam-components.css`；排行榜保留表格交互与分数状态样式。

比赛时间、key/考号登录、CSP 提交目录、`.txt/.TXT` 识别和赛中零反馈规则沿用既有实现。浏览器验收另修复了旧回执缺失 `</table>` 导致后续内容错位的问题，以及题库目录没有随 `CSP_EXAM_DATA_DIR` 隔离的问题。

## 文件位置与运行

- `csp_exam/web/templates/tabler-page.html`：官方布局的页面外壳。
- `csp_exam/web/templates/tabler-auth.html`：居中登录布局。
- `csp_exam/web/tabler_theme.py`：呈现类名适配，避免改动业务字段和脚本。
- `csp_exam/web/static/vendor/tabler/1.6.1/`：未修改的上游资产、许可证、完整性清单。
- `csp_exam/tools/vendor_tabler.py`：需要重新取得同版本资产时使用；正常部署不必执行。

CSS、JavaScript、题面 KaTeX 都由本站提供，页面不依赖外部 CDN、远程字体、npm 安装或构建服务。发布包包含 HTML 模板及所有运行资产。供应商文件更新后应重新核对版本和完整性，而不是直接覆盖线上文件。

Tabler 当前官方仓库列出的浏览器基线为 Chrome/Edge 123+、Firefox 128+、Safari 17.5+；本次实际验收使用 Codex 内置 Chromium 浏览器。旧版考场浏览器需要单独验证，尚未宣称兼容。

## 本地预览与验收

隔离预览地址为 `http://127.0.0.1:18081`，只监听本机。题库使用第 001 套模拟题，考生全部为虚构资料。预览工具禁用沙箱请求，不提供模拟的 AC 分数；这些工具与数据均不进入正式源码包。服务器 LiteOJ 未做任何修改。

浏览器实际验收记录与最新测试结果见 [本地验收记录](本地验收记录.md)。项目外 `平台/界面验收/` 保存实际截图。重新运行本地预览可执行项目外的 `.tools/run_tabler_preview.py`；学生考号 `GD-J12345`，本地预览 key 为 `local-preview-key`，均为虚构测试凭据。
